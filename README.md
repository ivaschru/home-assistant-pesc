# PESC Personal Account for Home Assistant

[![HACS validation](https://github.com/ivaschru/home-assistant-pesc/actions/workflows/hacs.yml/badge.svg)](https://github.com/ivaschru/home-assistant-pesc/actions/workflows/hacs.yml)
[![Tests](https://github.com/ivaschru/home-assistant-pesc/actions/workflows/tests.yml/badge.svg)](https://github.com/ivaschru/home-assistant-pesc/actions/workflows/tests.yml)

Неофициальная HACS-интеграция личного кабинета **ПСК / ПЭС** на
`ikus.pesc.ru`. Она автоматически проходит вход по логину, паролю и TOTP,
раз в час обнаруживает все поддерживаемые объекты внутри одного кабинета и
создаёт сущности Home Assistant. Отдельное действие позволяет передать
показания выбранного счётчика.

> Интеграция использует приватный API официального веб-интерфейса. ПСК не
> публикует контракт этого API, поэтому обновление личного кабинета может
> потребовать обновления интеграции. Проект не связан с АО «Петербургская
> сбытовая компания».

## Возможности

- автоматический вход по телефону или email, паролю и RFC 6238 TOTP;
- автоматическое обнаружение нескольких объектов/лицевых счетов;
- обновление данных раз в час и поддержание короткой API-сессии;
- сенсоры баланса, суммы к оплате, переплаты, текущего счёта и срока передачи;
- сенсор последнего принятого показания для каждой шкалы счётчика;
- бинарный сенсор доступности передачи показаний;
- действие `pesc.submit_readings` с локальной проверкой объекта, счётчика,
  всех шкал, предыдущих значений, разрядности и точности;
- полностью локальная генерация TOTP – секрет не отправляется сторонним
  сервисам.

Сейчас автоматически выбираются услуги с кодом поставщика `PSK`. Другие
услуги в том же кабинете не превращаются в сущности этой интеграции.

## Установка через HACS

1. Откройте HACS → Integrations → меню → Custom repositories.
2. Добавьте `https://github.com/ivaschru/home-assistant-pesc` с категорией
   Integration.
3. Установите **PESC Personal Account** и перезапустите Home Assistant.
4. Откройте Settings → Devices & services → Add integration →
   **PESC Personal Account**.
5. Введите логин, пароль и постоянный TOTP-секрет.

В поле TOTP можно вставить либо Base32-секрет, либо полный URI вида
`otpauth://totp/...`. Одноразовый шестизначный код не подходит: для повторного
входа интеграции нужен постоянный секрет.

Home Assistant хранит логин, пароль и TOTP в своей конфигурационной записи.
Защитите каталог конфигурации и резервные копии Home Assistant как секретные
данные. Диагностика интеграции не включает реквизиты, адреса, номера счетов,
серийные номера и идентификаторы объектов.

## Передача показаний

Интеграция ничего не отправляет автоматически после установки. Для записи
нужно явно вызвать действие:

```yaml
action: pesc.submit_readings
data:
  account_id: 123456
  meter: "12345678"
  readings:
    День: 12345
    Ночь: 6789
response_variable: pesc_result
```

`account_id`, номер/регистрация счётчика и названия шкал доступны в атрибутах
созданных сущностей. Если у объекта ровно один счётчик, поле `meter` можно не
указывать. Вместо локализованных названий шкал допускаются их числовые
`scale_id`.

Действие требует значения для **всех** шкал. Оно не допускает значение меньше
последнего принятого, неизвестную шкалу, неактивный счётчик или передачу вне
разрешённого ПСК периода. Если ПСК сообщает точность счётчика `0`, дробное
значение будет отклонено, а не округлено. В автоматизации Home Assistant такое
значение следует преобразовать осознанно, например `{{ states('sensor.x') |
int(0) }}`.

Для нескольких настроенных кабинетов укажите `config_entry_id`. Ответ действия
не содержит токенов или учётных данных:

```yaml
account_id: 123456
meter_serial: "12345678"
readings:
  День: 12345.0
  Ночь: 6789.0
accepted: true
```

Перед включением автоматической ежемесячной отправки рекомендуется сначала
несколько циклов сравнить сенсоры Home Assistant с кабинетом ПСК и отправлять
уведомление с подготовленными значениями для ручного подтверждения.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[test]'
.venv/bin/pytest
.venv/bin/ruff check .
```

Пожалуйста, не прикладывайте к issues логин, пароль, TOTP URI, токены, адрес,
номер лицевого счёта или реальные показания. Redacted diagnostics достаточно
для первичной диагностики.
